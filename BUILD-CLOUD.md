# Как получить .exe, ничего не устанавливая

Собирать будет сервер GitHub. На твоём компьютере не нужны ни Rust,
ни Build Tools, ни даже Node.js — только браузер.

Занимает минут пятнадцать в первый раз. Дальше — одна кнопка.

---

## Шаг 1. Аккаунт

Если нет — заведи на https://github.com. Бесплатно.

## Шаг 2. Создать репозиторий

1. Нажми `+` в правом верхнем углу → **New repository**
2. Название: `peredyshka`
3. Выбери **Public** (для приватных репозиториев сборка тоже работает,
   но лимит минут меньше)
4. **Create repository**

## Шаг 3. Загрузить файлы

На странице пустого репозитория нажми ссылку
**uploading an existing file**.

Распакуй архив `peredyshka-tauri.zip` у себя. Внутри будет папка
`peredyshka` — открой её и перетащи в браузер **всё содержимое**:
папки `src`, `src-tauri`, `test`, `.github` и файлы `package.json`,
`README.md`.

> Если папка `.github` не видна в проводнике — включи показ скрытых
> файлов: в проводнике вкладка «Вид» → галочка «Скрытые элементы».
> Эта папка обязательна, без неё сборки не будет.

Внизу страницы нажми **Commit changes**.

## Шаг 4. Запустить сборку

1. Вкладка **Actions** вверху страницы репозитория
2. Если спросит разрешение на запуск — нажми
   **I understand my workflows, go ahead and enable them**
3. Слева выбери **Сборка установщика**
4. Справа кнопка **Run workflow** → ещё раз **Run workflow**

Пойдёт сборка. Первый раз — минут 5–8, дальше быстрее за счёт кэша.
Обнови страницу, чтобы видеть прогресс. Зелёная галочка — готово.

## Шаг 5. Забрать установщик

Нажми на завершившуюся сборку. Внизу страницы блок **Artifacts**,
в нём — **Peredyshka-Windows**. Скачается zip, внутри `.exe`.

Это и есть установщик. Запускается двойным кликом, ничего
дополнительно не требует.

---

## Как сделать ссылку, по которой скачает любой

Артефакты из шага 5 доступны только тем, кто залогинен в GitHub.
Чтобы получилась публичная ссылка «скачать по клику»:

1. На главной странице репозитория справа — **Releases** → **Create a new release**
2. **Choose a tag** → впиши `v1.0.0` → **Create new tag**
3. **Publish release**

Сборка запустится сама и через несколько минут прикрепит `.exe`
к релизу. Ссылка вида
`github.com/твой-логин/peredyshka/releases/latest`
работает для всех, без регистрации.

---

## Что нужно тому, кто скачивает

Ничего. Windows 10 или 11 — и всё, WebView2 в них уже встроен.

Windows при первом запуске покажет синее окно
«Windows защитила ваш компьютер» — это стандартное предупреждение для
любой программы без платной подписи разработчика. Нажать
**Подробнее** → **Выполнить в любом случае**.

---

## Если сборка упала

Открой упавший шаг в Actions, там будет красный текст с ошибкой.
Пришли его — разберёмся. Чаще всего это опечатка при загрузке файлов:
не загрузилась папка `.github` или потерялась `src-tauri/icons`.
