# Передышка

Компактный таймер перерывов для Windows. Чёрное поле, белая рамка, оранжевый акцент. Версия 1.2.0.

## Что изменилось

- Вкладки «Таймер» и «Настройки». Выбор нагрузки, упражнений и ссылка «Глеб Ягодкин · Поддержать» находятся только в настройках.
- 15 движений и вариантов: приседания, отжимания, выпады, мостик, упражнения для корпуса и спины. Три уровня, выбор групп, исключение отдельных упражнений и разрешение работы на полу.
- Комплексы под 1, 3, 5 и 10 минут с подготовкой, подходами, отдыхом и восстановлением. На обычном уровне с полом доступны 11 движений; другие варианты зависят от условий и уровня.
- Целевые повторы, три подсказки по технике и две статичные позы SVG. Для упражнений на стороны явно указаны дозировка и сторона.
- Автоматические переходы с короткими звуковыми сигналами. «Подход выполнен» начинает отдых раньше, сохраняя время следующего подхода. Замены нет.
- Рамка и кнопки сохраняют положение при смене движения. На маленьком экране содержимое карточки прокручивается внутри рамки.

## Как пользоваться

На вкладке «Таймер» выбери время работы и перерыва и нажми «Запустить». За 30 секунд до перерыва появится предупреждение. Можно отложить его на пять минут, до трёх раз за рабочий период.

Во вкладке «Настройки» выбери интенсивность, группы и условия. Необязательные вопросы помогают уточнить нагрузку отдельно для рук и ног. Все упражнения без прыжков. Изменения сохраняются автоматически и применяются к следующему перерыву. Если подходящих упражнений нет, приложение объяснит причину; перерыв пройдёт без упражнений.

В начале перерыва есть 10–15 секунд на подготовку. Дальше приложение само переключает подходы и отдых. Повторы считаются самостоятельно. Кнопку «Подход выполнен» нажимать не обязательно. Она не завершает весь перерыв. «Завершить перерыв» и Escape записывают пропуск; автоматическое окончание засчитывает время отдыха, а не подтверждает физическое выполнение движений.

В мягком режиме окно не разворачивается поверх других программ. Крестик прячет приложение в трей; выход — через меню трея. При запуске с Windows таймер начинает работать в трее. Ручной запуск ждёт нажатия «Запустить». После обновления очень старой версии один раз выключи и включи автозапуск, чтобы Windows сохранила аргумент `--autostart`.

## Сборка EXE

Инструкция: [BUILD-CLOUD.md](BUILD-CLOUD.md). GitHub Actions собирает установщик NSIS. Готовый файл после успешной сборки находится в `Artifacts → Peredyshka-Windows`. Архив исходников сам по себе не является установщиком.

## Архитектура

Tauri 2: HTML/CSS/JavaScript без фронтенд-фреймворка; Rust управляет окном, треем, автозапуском, уведомлениями и внешней ссылкой. Настройки и история хранятся локально в WebView2. Сервера и учётной записи нет.

- `src/exercises.js`: движения, фильтрация, дозировки, планировщик и временная шкала.
- `src/illustrations.js`: статичные векторные схемы.
- `src/training-settings.js`: интерфейс выбора нагрузки и упражнений.
- `src/app.js`: таймер, переходы, статистика и отображение текущего подхода.
- `src/index.html`, `src/styles.css`: интерфейс и геометрия.
- `src-tauri/src/main.rs`: системные команды.

## Проверки

Node.js 24: `npm ci`, затем `npm test`. Для интерфейса: `npx playwright install chromium`, затем `npm run test:ui`. Можно использовать установленный Edge, задав переменную `BROWSER_CHANNEL=msedge`.

Тесты проверяют работу/отдых, сон, паузу, статистику, автопереходы, раннее завершение, сохранение фильтров, обе стороны и пустой набор. Планировщик проверяется на 5760 сочетаниях длительности, уровня, групп и работы на полу. Браузер проверяет 145 переходов на пяти размерах окна, клавиатуру и отдельную вкладку настроек. Скриншоты сохраняются в `artifacts/`.

Для локальной нативной сборки нужны Rust stable, Visual Studio Build Tools C++ и Windows SDK: `npm run build -- --ci -- --locked`. Установщик: `src-tauri/target/release/bundle/nsis/*.exe`.

Источники и правила подбора: [EXERCISES.md](EXERCISES.md). Результаты аудита и ограничения проверки: [AUDIT.md](AUDIT.md).
