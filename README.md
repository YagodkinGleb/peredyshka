# Передышка

Таймер перерывов, который не даёт просидеть за компьютером весь день.
Каждый перерыв предлагает упражнение, подобранное под длину этого перерыва.

Собран на Tauri: установщик около 6 МБ, на диске около 13 МБ,
в памяти около 60 МБ вместо 150 у прошлой версии на Electron.

---

## Что нужно поставить один раз

Node.js у тебя уже есть. Дополнительно нужны две вещи:

### 1. Visual Studio Build Tools

Скачай **Build Tools for Visual Studio** отсюда:
https://visualstudio.microsoft.com/visual-cpp-build-tools/

При установке отметь галочку **«Разработка классических приложений на C++»**
(Desktop development with C++). Остальное не нужно. Займёт около 2 ГБ.

### 2. Rust

https://rustup.rs — скачай `rustup-init.exe`, запусти, нажми `1`
(установка по умолчанию). Займёт пару минут.

После установки **закрой и открой PowerShell заново**, иначе он не увидит
новые команды. Проверь:

```powershell
rustc --version
```

Должна появиться версия 1.77 или выше.

WebView2 ставить не нужно — он уже входит в Windows 10 и 11.

## Сборка

В папке проекта:

```powershell
npm install
npm run build
```

Первая сборка идёт 3–6 минут: Rust компилирует зависимости с нуля.
Последующие — секунд 30.

Готовый установщик появится здесь:

```
src-tauri\target\release\bundle\nsis\Передышка_1.0.0_x64-setup.exe
```

Запусти его — программа поставится в профиль пользователя,
без прав администратора.

### Посмотреть на приложение, не собирая установщик

```powershell
npm run dev
```

Откроется окно приложения. Правки в `src/` подхватываются перезапуском.

```powershell
npm test
```

Прогоняет 63 проверки: переходы фаз, реакцию на сон компьютера, отсрочки,

Полезно, если будешь что-то править в `src/app.js`.

## Как пользоваться

- **Крестик** не закрывает программу, а прячет её в трей
- **Клик по иконке в трее** — показать окно
- **Правый клик по иконке** — автозапуск при старте Windows и выход
- Цвет иконки в трее показывает фазу: янтарная — работа, зелёная — перерыв.
  Наведи мышь — увидишь, сколько осталось
- **Пробел** — старт и стоп, когда окно в фокусе
- **Esc** во время перерыва — пропустить его

### Мягкий режим

Переключатель в настройках. Когда включён, программа не разворачивается
поверх других окон, а только присылает уведомление. Включи, если много
созвонов или демонстраций экрана.

### Отсрочка

За 30 секунд до перерыва внизу окна появляется предупреждение с кнопкой
«Отложить на 5 минут». Отложить можно три раза подряд, дальше перерыв
начнётся принудительно.

## Упражнения

62 упражнения, разбитых по длине перерыва — под физиологию сидячей работы:

| Перерыв | Уровень | Что предлагается |
|---|---|---|
| 1–2 мин | микро | Глаза, шея, запястья, подъёмы на носки, дыхание |
| 3–6 мин | короткий | Приседания, растяжка, планка, мобилизация |
| 7+ мин | длинный | Круговые, бёрпи с разминкой, прогулка на улице |

Логика простая: бёрпи на минутном перерыве вредны — вернёшься к работе
с пульсом 140 и убитой концентрацией. А растяжка глаз на пятнадцатиминутном
перерыве — упущенная возможность.

Программа не повторяет упражнение, пока не переберёт другие, и не даёт
две нагрузки подряд на одну группу мышц.

## Если сборка не пошла

**`error: linker link.exe not found`**
Не установлены Build Tools или не отмечена галочка C++. Вернись к шагу 1.

**`rustc 1.75` или ниже**
Обнови: `rustup update`.

**Ошибка в строках про `autostart`**
Автозапуск — единственная необязательная часть. Если компилятор ругается
именно на неё, её можно убрать без вреда для остального:

1. В `src-tauri/Cargo.toml` удали строку `tauri-plugin-autostart = "2"`
2. В `src-tauri/src/main.rs` удали строку `use tauri_plugin_autostart::ManagerExt;`,
   блок `.plugin(tauri_plugin_autostart::init(...))` целиком,
   переменные `autostart_on`, `auto_i`, `auto_handle`,
   ветку `"autostart" => { ... }` и упоминание `&auto_i` в списке пунктов меню
3. В `src-tauri/capabilities/default.json` удали строку `"autostart:default"`

Программа соберётся и будет работать, пропадёт только пункт автозапуска
в меню трея. Добавить в автозагрузку можно вручную: `Win+R`, `shell:startup`,
положить туда ярлык программы.

**Антивирус ругается на собранный .exe**
Нормально для неподписанных программ. Подпись стоит денег и требует
сертификата разработчика.

## Два файла на выходе

После `npm run build` в папке `src-tauri\target\release\` появятся:

**1. `peredyshka.exe`** — сама программа, одним файлом, около 9 МБ.
Ничего не устанавливает, запускается двойным кликом откуда угодно —
хоть с флешки. Всё содержимое (интерфейс, упражнения, иконки) вшито
внутрь. Именно этот файл удобнее всего просто скинуть человеку.

**2. `bundle\nsis\Передышка_1.0.0_x64-setup.exe`** — установщик,
около 6 МБ. Ставит программу в систему, создаёт ярлык в меню Пуск
и позволяет удалить через «Установка и удаление программ».
Нужен, если хочешь, чтобы у человека всё выглядело как обычная программа.

Оба работают на любой Windows 10 и 11 без единой дополнительной установки.
